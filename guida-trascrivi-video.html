Come funziona

La skill e composta da due file: uno script Python che scarica la trascrizione, e un file Markdown che dice a Claude come usarlo.

Lo script Python — scarica_trascrizione.py

Usa la libreria youtube-transcript-api. Prova prima italiano, poi inglese, poi qualsiasi lingua disponibile. 

"""
Scarica la trascrizione di un video YouTube dato l'URL.
Uso: python trascrivi_video.py https://youtu.be/VIDEO_ID
"""

import sys, re
from youtube_transcript_api import YouTubeTranscriptApi, NoTranscriptFound

def estrai_video_id(url):
    patterns = [r'v=([^&\n]+)', r'youtu\.be/([^?\n]+)', r'embed/([^?\n]+)']
    for p in patterns:
        m = re.search(p, url)
        if m: return m.group(1)
    return None

def scarica_trascrizione(url):
    video_id = estrai_video_id(url)
    ytt = YouTubeTranscriptApi()
    for lang in ['it', 'en']:
        try:
            transcript = ytt.fetch(video_id, languages=[lang])
            testo = ' '.join([e.text for e in transcript])
            print(f"[LINGUA: {lang}] [CARATTERI: {len(testo)}]\n")
            print(testo)
            return
        except NoTranscriptFound:
            continue
    print("ERRORE: nessuna trascrizione disponibile per questo video.")

if __name__ == "__main__":
    scarica_trascrizione(sys.argv[1])

Il file Markdown della skill — trascrivi-video.md

Questo e il file che Claude legge quando invochi /trascrivi-video. Salvalo in ~/.claude/commands/trascrivi-video.md per averlo disponibile ovunque. 

# Skill: /trascrivi-video

Scarica la trascrizione di un video YouTube e la restituisce
pronta da usare. Non serve uscire da Claude Code.

---

## Input

$ARGUMENTS — URL del video YouTube.

Esempi:
- `/trascrivi-video https://www.youtube.com/watch?v=ID`
- `/trascrivi-video https://youtu.be/ID`

---

## Procedura

### Step 1 — Scarica la trascrizione
Esegui:
```
python ~/.claude/scripts/trascrivi_video.py URL_DEL_VIDEO
```

### Step 2 — Mostra il risultato
Mostra lingua, video ID, lunghezza in caratteri, prime 500 parole.
Poi chiedi: "Cosa vuoi fare con questa trascrizione?"

Opzioni suggerite:
- Salvarla nell'inbox del progetto
- Estrarre i punti chiave
- Usarla come base per un post

### Step 3 — Salva se richiesto
Crea un file in 00_Inbox/ con il testo completo e la fonte.

---

## Note
- Libreria: youtube-transcript-api (pip install youtube-transcript-api)
- Prova prima italiano, poi inglese, poi qualsiasi lingua disponibile
- Non funziona se il creatore ha disabilitato i sottotitoli

Come installare

Passo 1 — Installa la libreria Python

pip install youtube-transcript-api

Passo 2 — Salva lo script

Crea la cartella ~/.claude/scripts/ e salva lo script come trascrivi_video.py.

Passo 3 — Salva la skill

Crea la cartella ~/.claude/commands/ e salva il file Markdown come trascrivi-video.md. Riavvia Claude Code.

Passo 4 — Testa

/trascrivi-video https://youtu.be/dQw4w9WgXcQ

Se vedi [LINGUA: en] [CARATTERI: 42000] seguito dal testo, funziona.

Esempi d'uso pratico

  • Analisi interviste — trascrivi un'intervista a un founder o investitore, poi chiedi a Claude di estrarre le citazioni piu interessanti o i pattern ricorrenti.
  • Smontare un talk — dai un TED talk o una conferenza, estrai i punti chiave, la struttura narrativa, le domande che apre.
  • Materiale da conferenze — segui una conferenza YouTube in streaming, trascrivi i talk che ti interessano e archiviali nel tuo inbox.
  • Ricerca competitiva — trascrivi video di concorrenti o creator nel tuo settore, analizza linguaggio, posizionamento, argomenti ricorrenti.

Quando NON usarla

  • Video con sottotitoli disabilitati — alcuni creator disabilitano le trascrizioni. La skill lo segnala con un errore chiaro.
  • Audio non chiaro o dialetti — le trascrizioni auto-generate di YouTube sono generate dall'audio. Se l'audio e distorto o dialettale, la trascrizione sara inaccurata.
  • Video molto brevi (sotto 2 minuti) — per clip brevi e spesso piu veloce ascoltare direttamente.
  • Lingue rare — la skill prova italiano e inglese. Per altre lingue, la trascrizione potrebbe non essere disponibile o di qualita inferiore.
