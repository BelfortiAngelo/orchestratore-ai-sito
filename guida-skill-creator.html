Come ho smesso di rispiegare lo stesso task ogni settimana.

Skill /skill-creator Comandi custom

Il problema: Claude e bravo ma non ha memoria dei task

Ogni settimana faccio le stesse cose. Trascrivo video YouTube per estrarne contenuti. Apro una sessione di lavoro e devo ricaricare il contesto. Scrivo bozze LinkedIn seguendo sempre la stessa struttura.

Il problema: ogni volta che iniziavo uno di questi task, perdevo 5-10 minuti a rispiegare a Claude come farlo. "Usa questo formato. Salva qui. Chiedi prima quest'altro." Lo stesso copione, ogni volta.

Il costo nascosto

Non e solo il tempo. E che ogni volta il risultato era leggermente diverso, perche il contesto che davo era sempre un po' diverso. Nessuna coerenza, nessuna standardizzazione. Stavo usando uno strumento potente in modo manuale.

Cos'e una skill in Claude Code

Una skill e un file di testo Markdown che Claude legge come un set di istruzioni permanenti. Quando scrivi /nome-skill nella chat, Claude carica quel file e lo esegue.

Non e codice. Non e programmazione. E un documento con tre cose:

  • Cosa deve fare Claude quando invochi il comando
  • Quali input aspettarsi
  • Quali step seguire, in quale ordine

Scritto una volta, funziona per sempre. Ogni volta che invochi la skill, Claude parte gia con il contesto completo. Zero rispiegazioni.

Come funziona /skill-creator

/skill-creator e una meta-skill: una skill che genera altre skill. Invece di scrivere il file .md a mano, descrivi il problema a Claude e lui costruisce la skill per te.

Il flusso e questo:

  • Invochi /skill-creator
  • Descrivi il task che vuoi automatizzare ("ho bisogno di una skill che trascriva video YouTube")
  • Claude fa le domande giuste per capire il contesto — dove salvare, che formato, quali step
  • Genera il file .md con la struttura corretta
  • Lo salva nella cartella giusta

Il risultato e un file pronto, testato, con la struttura che Claude Code si aspetta. Non devi sapere come si scrive una skill: basta saper descrivere cosa vuoi fare.

Esempio concreto: come ho creato /trascrivi-video

Ogni settimana trascrivevo video YouTube per usarli come base per i contenuti. Il processo era sempre lo stesso: copiare l'URL, andare su un sito esterno, copiare la trascrizione, incollarla da qualche parte.

Ho invocato /skill-creator e descritto il problema. Claude ha chiesto: dove vuoi salvare le trascrizioni? Che formato preferisci? Vuoi che ti chieda cosa fare con il testo dopo averlo scaricato?

Dieci minuti dopo avevo /trascrivi-video: una skill che prende l'URL del video, scarica la trascrizione in italiano (o inglese se non disponibile), mostra un'anteprima e chiede cosa farne. Tutto senza uscire da Claude Code.

Il file generato — struttura base:

# Skill: /trascrivi-video

Scarica la trascrizione di un video YouTube e la restituisce
pronta da usare.

---

## Input

$ARGUMENTS — URL del video YouTube.

Esempi:
- `/trascrivi-video https://youtu.be/abc123`

---

## Procedura

### Step 1 — Scarica la trascrizione
Esegui lo script Python con l'URL passato come argomento.

### Step 2 — Mostra il risultato
Mostra lingua, durata, prime 500 parole come anteprima.
Chiedi: "Cosa vuoi fare con questa trascrizione?"

### Step 3 — Salva se richiesto
Crea un file in Claude-Project/00_Inbox/ con il testo completo.

Skill globali vs skill di progetto

Ci sono due posti dove salvare una skill, e la differenza e importante:

  • Skill globale — salvata in ~/.claude/commands/. Disponibile in qualsiasi chat, su qualsiasi progetto. Usala per task trasversali: trascrivi video, scrivi post LinkedIn, apri sessione.
  • Skill di progetto — salvata in [progetto]/.claude/commands/. Disponibile solo quando lavori in quella cartella. Usala per task specifici di un progetto: analizza commessa, genera preventivo, aggiorna status.

Il principio: se la usi ovunque, salvala in globale. Se ha senso solo in un contesto, salvala nel progetto.

Le skill che ho gia costruito

Queste sono le skill operative nel mio sistema. Le prossime guide le raccontano una per una:

  • /apri-sessione — carica il contesto del progetto attivo, legge STATUS.md, imposta la sessione
  • /chiudi-sessione — cristallizza la sessione in STATUS.md, definisce il prossimo step
  • /trascrivi-video — scarica trascrizioni YouTube direttamente da Claude Code
  • /leggi-reddit — analizza thread Reddit per estrarne segnali e insight utili

Ogni skill ha una storia dietro: un task che facevo a mano, un problema ripetuto, una soluzione costruita in 10 minuti. Le guide arrivano.

La logica del sistema

Le skill non sostituiscono il pensiero. Automatizzano l'esecuzione. Quando sai gia come fare una cosa e la fai sempre allo stesso modo, c'e una skill da costruire. Quando ancora stai capendo come approcciarla, tieni la flessibilita della chat libera.
